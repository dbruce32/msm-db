MSM Database API

A free, static JSON API for My Singing Monsters data. No authentication required. Fetch from any app or website.

Base URL

https://dbruce32.github.io/msm-db/api

Endpoints

GET /monsters/index.json

Returns a manifest of all monsters with their name, slug, class, and elements.

GET /monsters/{slug}.json

Returns full data for a single monster, including breeding combos per island.

GET /islands/index.json

Returns all islands with their element pools.

Usage Examples

Fetch all monsters (JavaScript)

const res = await fetch('https://dbruce32.github.io/msm-db/api/monsters/index.json');
const data = await res.json();
console.log(`Total monsters: ${data.total}`);
data.monsters.forEach(m => console.log(m.name, m.elements));

Fetch a specific monster

const res = await fetch('https://dbruce32.github.io/msm-db/api/monsters/bowgart.json');
const bowgart = await res.json();
console.log(bowgart.name);          // "Bowgart"
console.log(bowgart.elements);      // ["Plant", "Water", "Cold"]
console.log(bowgart.breeding);      // { "Plant Island": { common: {...}, epic: {...} }, ... }

Fetch all islands

const res = await fetch('https://dbruce32.github.io/msm-db/api/islands/index.json');
const data = await res.json();
data.islands.forEach(island => console.log(island.name, island.elements));

Using with Python

import requests

monsters = requests.get('https://dbruce32.github.io/msm-db/api/monsters/index.json').json()
print(f"Total monsters: {monsters['total']}")

bowgart = requests.get('https://dbruce32.github.io/msm-db/api/monsters/bowgart.json').json()
print(bowgart['breeding']['Plant Island']['common'])

Data Format

Monster Object

{
  "name": "Bowgart",
  "class": "Natural",
  "elements": ["Plant", "Water", "Cold"],
  "variants": ["Rare Bowgart", "Epic Bowgart"],
  "breeding": {
    "Plant Island": {
      "common": {
        "pair": ["Furcorn", "Toe Jammer"],
        "time": "12h",
        "enhanced_time": "9h"
      },
      "epic": {
        "pair": ["Clamble", "Oaktopus"],
        "time": "1d 5h",
        "enhanced_time": "21h 45m"
      }
    }
  }
}

Slug Convention

Monster slugs are the lowercase name with non-alphanumeric characters replaced by hyphens:
"Toe Jammer" → toe-jammer, "T-Rox" → t-rox, "PomPom" → pompom

CORS

GitHub Pages serves all responses with permissive CORS headers. You can fetch from any origin — no proxy needed.
